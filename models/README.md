# Models

The baseline saves its model.joblib alongside its metrics and split manifest in
outputs/baseline/<run timestamp>/, keeping the complete run together.
This models/ directory is reserved for later selected deployment models.

Only load models generated by your own project. Pickle/joblib loading can execute
code; do not load downloaded or otherwise untrusted model files. Package versions,
feature ID, method ID and class order must match the model's metadata.
